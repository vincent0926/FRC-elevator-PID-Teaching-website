# FRC 電梯／手臂 PID 與前饋參數學習網站

FRC 9427 的電梯與手臂調參教學工具。目標是讓隊員搞懂前饋和 PID，最後能自己把機構調好，而不是只會抄數字。進站先選機構：電梯（直線上下）或單關節旋轉手臂。

## 網址

**https://vincent0926.github.io/FRC-elevator-PID-Teaching-website/**

推到 `main` 後 GitHub Actions 會自動測試、建置，並把網站推到 `gh-pages` 分支，約 1–2 分鐘後網址就是最新版本（網頁上方會出現「有新版本」提示）。
部署進度看 repo 的 Actions 分頁。

### 手臂（單關節旋轉手臂）

| 樓層 | 功能 | 狀態 |
|---|---|---|
| 進站選擇 | 每次打開網站先選電梯或手臂（同一分頁重新整理不用重選）；導覽列「換機構」隨時切換，兩邊資料分開存；電梯的分享連結直接進電梯 | ✅ |
| 1F 計算參數 | 手臂質量、長度、重心、末端負載、齒比、角度範圍、角度感測器（TalonFX 內建編碼器或 CANcoder）→ kG（水平時，乘 cos θ）、kV、kA、kP（每度幾伏特）、Motion Magic；參數卡附 Phoenix 6 轉數制；五個教學關卡（重力力矩填空練習、為什麼是 cos θ、前饋推導、把手臂當電梯會怎樣〔模擬比較〕、PID 起始值） | ✅ |
| 3F 模擬 | 手臂側視圖；理論值／自訂、理想／真實模型（摩擦、電流限制、電壓飽和、電池壓降、效率、感測延遲與雜訊）；重力型態 Arm_Cosine／常數 kG；7 個教學情境（把手臂當電梯、沒有 kG、轉過直立、負載變重、編碼器零點不在水平、用 kI 補 kG、kP 太大）；照順序調；積分防飽和；指標用角度、達標標準可調 | ✅ |
| 2F 調參建議、4F 實機教學、程式輸出 | 日誌診斷、SysId、手臂的常見的坑；Java 輸出（TalonFX 內建編碼器／CANcoder） | 製作中（下一版） |

還沒做：手臂 2F、4F 與程式輸出；英文版；找新隊員實際試用，檢查學習成效（需要真人）。

## 開發

```
npm install
npm run dev     # http://localhost:5173
npm test        # 單元測試（core/ 全部有測試）
npm run build
```

需要 Node.js 20 以上。
