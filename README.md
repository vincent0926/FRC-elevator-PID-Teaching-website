# FRC 9427 機構調參學習網站

**作者：FRC9427**

給 FRC 9427 隊員用的前饋與 PID 學習網站。目標是讓你**搞懂**每個參數在做什麼，最後自己把機構調好，不是抄數字。

**👉 打開網站：https://vincent0926.github.io/FRC-elevator-PID-Teaching-website/**

手機、平板、電腦都能用；第一次開過之後，沒網路也能用（PWA）。

> 網站只做計算、模擬、診斷和教學，**不連線機器人、不寫馬達參數**。急停一律用 Driver Station。

## 三步上手

1. **選機構**：進站先選電梯、單關節手臂或射球飛輪。
2. **從 1F 往上走**：網站像一棟樓，每一層做一件事（見下表）。
3. **看不懂就點「怎麼用這一頁？」**：每一層標題旁都有；導覽列最上面有完整的「使用說明」。

## 三種機構

| 機構 | 控制方式 | 重點 |
|---|---|---|
| **電梯** | 位置控制（Motion Magic） | 直線上下，重力固定，kG 抵銷 |
| **單關節手臂** | 位置控制（Motion Magic，Arm_Cosine） | 旋轉，重力跟著 cos θ 變 |
| **射球飛輪** | 速度控制（VelocityVoltage，rps） | 連射時轉速撐不撐得住、球進不進 |

## 每一層做什麼

| 樓層 | 做什麼 | 電梯 | 手臂 | 射球飛輪 |
|---|---|:-:|:-:|:-:|
| **1F 計算參數** | 填機構資料，算出 kS、kG、kV、kA、kP 起始值和 Motion Magic；教學關卡附檢核題 | ✅ | ✅ | ✅ |
| **2F 調參建議** | 匯入 .wpilog（或 3F 送來的模擬資料），照順序找出第一個要修的問題，一次只改一個參數 | ✅ | ✅ | — |
| **3F 模擬** | 動畫加圖表，親手拖滑桿調參數，馬上看結果；理想模型和真實模型（電壓飽和、摩擦、電流限制、延遲……）可以逐項開關 | ✅ | ✅ | ✅ |
| **4F 實機資料教學** | 安全須知、用 AdvantageKit 錄日誌、SysId、常見的坑、兩點法量 kS／kG、期末檢核 | ✅ | ✅ | — |

### 電梯、手臂建議的順序

**1F** 算起始值 → **3F** 在模擬裡練習調 → **4F** 學怎麼安全地錄實機資料 → **2F** 匯入日誌，看下一步改哪個 → 上機驗證。

- **1F**：參數卡標明哪些能算、哪些一定要量；可以掃齒比、分享機構連結。最高速度和加速度會扣掉量到的 kS，沒量時標明是不含摩擦的理論上限。
- **2F**：先檢查資料，再照「物理限制 → 振盪 → 機構 → kG → kS → kV → kA → kP → kD」找問題；有引導模式和專家模式，附練習用的範例日誌。
- **3F**：教學情境（沒有 kG、用 kI 補 kG、積分飽和……）、照順序調、挑戰模式、模型校正、穩健性測試；達標標準可以自己改；滑桿可以切成 Phoenix 6 轉數制（rps），數字就是 `Slot0Configs`、`MotionMagicConfigs` 要填的值。
- **4F**：單元零（安全）必修，勾完才開放後面的單元。

### 射球飛輪的三種用法

點「射球飛輪」會先問你要哪一種（之後用導覽的「換機構」可以再選一次）：

| 用法 | 1F | 3F |
|---|---|---|
| **彈道** | 給距離，畫出每個砲台角度剛好進目標的軌跡，自己選一條，得到要幾 rps、砲台角度幾度、轉速可以差多少還會進 | 用選好的轉速和仰角連射 |
| **客製化** | 算 Slot0（kV、kA）、轉動慣量、最快到速；轉速 → 球速 → 進不進；三個教學關卡 | 機構、仰角、轉速、發數全部自己設 |
| **邊移動邊射** | 多填機器人往目標和側向的速度，算轉速、砲台角度和底盤要偏幾度（沒有砲塔）；打得進的範圍太窄時，告訴你速度、距離或轉速上限要改成多少；附機器人程式怎麼寫（Java） | 俯視圖看邊開邊射，比較「有補償」和「沒補償」進幾發 |

三種都可以：

- 設**轉速上限**（預設馬達空載轉速的 90%），超過的軌跡不能選。
- 選 FRC 2026 的**得分物件**（FUEL），一鍵**套用 2026 HUB 高度**。
- **砲台角度**：球往正上方是 0°，往目標倒角度變大，水平朝目標是 90°（= 90° − 仰角）。
- 選**球的另一邊**是固定導板或對面滾輪（上下夾射）。

## 要知道的限制

- 模擬是**教學用的近似模型**，不是馬達韌體的數值重現；模擬結果只能當起點，最後一定要上機驗證。
- 達標標準是教學用的，**不是 FRC 官方標準**。
- 2F 的診斷正確率是用本站模擬器產生的**合成資料**測的，還沒用真實 FRC 日誌驗證。
- 射球的球速和落點**不計空氣阻力**、假設球不打滑；邊移動邊射沒算程式到出球的延遲。上機一定要實際射幾發量落點。

## 從課程連進來（深層連結）

[FRC 9427 程式課程](https://vincent0926.github.io/FRC9427teaching-website/)可以用網址直接開到某個機構、情境或單元：

| 參數 | 值 | 作用 |
|---|---|---|
| `track` | `elevator`、`arm` | 直接進電梯或手臂，不用先選 |
| `scenario` | 3F 情境 id（`src/pages/simulate/simScenarios.ts`、`src/pages/arm/armScenarios.ts`） | 進 3F 時直接載入 |
| `section` | 元素 id，例如 `unit4`、`measure-ks` | 捲到該區塊，`<details>` 自動打開 |
| `from=course&ch=` | 章節編號 0–19 | 顯示「回到課程第幾章」 |

樓層用 hash（`#calc`、`#tune`、`#sim`、`#learn`），例如：

```
https://vincent0926.github.io/FRC-elevator-PID-Teaching-website/?track=elevator&scenario=noKg&from=course&ch=13#sim
```

參數只接受白名單格式，讀過就從網址拿掉。**改情境 id 或單元 id 時，課程的 `src/data/course.json` 也要一起改**，課程那邊的檢查腳本會比對。

## 開發

需要 Node.js 20 以上（CI 用 22）。

```
npm install
npm run dev        # 開發伺服器 http://localhost:5173
npm test           # Vitest 單元測試（src/core/ 全部要有測試）
npm run typecheck  # tsc
npm run lint       # oxlint
npm run build      # 輸出到 dist/
```

- **技術**：React + TypeScript + Vite，PWA。
- **部署**：推到 `main` 後，GitHub Actions 自動測試、建置、部署到 GitHub Pages，約 1–2 分鐘後網站更新，網頁上方會出現「有新版本」提示。
- **版本**：只以 `package.json` 為準，這份 README 的「目前進度」要一起改（`test/version.test.ts` 會檢查）。
- **瀏覽器測試**：Service Worker 會快取舊版，測建置結果時換新的瀏覽器設定檔或清掉 SW。
